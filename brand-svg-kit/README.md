# مُسدل · حزمة SVG

جميع الملفات البصرية SVG متجهية فعلية، بدون صور PNG/JPEG مدمجة. حروف اللوغو العربي والإنجليزي مسارات لا تحتاج تثبيت خط.

- logos: كلمة مُسدل وحدها، النسخة مع MUSDAL، والكلمة الإنجليزية؛ نسخ شفافة وعلى الأرضيتين.
- emblem: اللام الطويلة المختارة، بلون بورغندي وأوف وايت وعلى الأرضيتين.
- favicon: اللام بمساحة آمنة مربعة؛ يوجد ملف يتكيف مع الوضع الفاتح والداكن.
- patterns: أربع عائلات، لكل منها نسخة هادئة للموقع ونحاسية للتغليف ومعكوسة على بورغندي.
- colours: عينات الألوان والباليت.
- brand-overview.svg: عرض كامل للبراند بصيغة SVG.

تغيير width/height مع الحفاظ على viewBox يكبّر الملف دون بكسلة. استخدم الملف الشفاف للتركيب فوق التصميم، ونسخ on-off-white/on-burgundy للمعاينة أو عندما تكون الأرضية جزءًا من التصميم. الباترنز لها تكرار داخلي، وأبعادها مضاعفات صحيحة لوحدة التكرار؛ استخدمها مع CSS background-repeat أو داخل أدوات التصميم. لا تتمدد النسب أفقياً أو رأسياً.

الخلفية المعتمدة أوف وايت #FCFBF8، والبورغندي #5C1E32، والحجري #DDDAD3، والنحاسي #A77359. النحاسي للتفاصيل المحدودة، وخلفيات النصوص والمنتجات تبقى هادئة.

المصدر النهائي السابق كان صورًا، لذلك هذه إعادة بناء متجهية للرسومات المعتمدة مع الحفاظ على النسب؛ وليست ملف التصميم الأصلي قبل التوليد. الملفات قابلة للتكبير، لكن وضوح أيقونة16px يخضع لضيق مساحة العرض؛ افحصها بالحجم الفعلي.

تفاصيل الأصول والتتبع والقياسات في manifest.json.
