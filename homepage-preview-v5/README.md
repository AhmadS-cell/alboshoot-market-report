# معاينة مُسدل — الصفحة الرئيسية، النسخة الخامسة

الرابط العام: https://ahmads-cell.github.io/alboshoot-market-report/homepage-preview-v5/index.html

النسخة الحالية تشمل تعديلات 5 أكتوبر 2026: أرضية بيضاء، الهوية البورغندي، خط Noto Naskh Arabic الأصلي للنصوص والعناوين، مع أحجام أوضح وتباعد سطور مريح، أسهم هيرو أنعم، أسماء فئات بالرمادي المعتمد وأسهم قريبة، مسافات مريحة، وأسعار دون العبارة التوضيحية.

`index.html` و`assets/` هما المعاينة التفاعلية المنشورة. الملفات في `source/` مرجع للواجهة؛ التطوير المحلي الكامل موجود في مشروع `homepage-preview-v5` على جهاز العمل. هذا البناء مهيأ لمسار GitHub Pages المحدد أعلاه.

يمكن تجربة بانرات الهيرو اليدوية والبحث والتنقل بين المنتجات وقائمة الموبايل. روابط المنتجات تفتح مخططات التقرير الحالية. لا يوجد ربط للشراء أو حساب العميل؛ هذه نسخة لمراجعة الفريق قبل التنفيذ على سلة.

الصورة والشعار والفونت والباترن أصلية من الأصول المعتمدة. التحقق المحلي شمل 1440 و390 بكسل وغياب التجاوز الأفقي. المرحلة التالية: التغليف وملف تسليم المصمم والطباعة بعد تأكيد المقاسات والخامات.

تحديث قسم التفاصيل للموبايل: النص والرابط فوق صورة النسيج مباشرة، دون لوحة سوداء مستقلة أسفلها. الرابط: «شاهد القطعة».
