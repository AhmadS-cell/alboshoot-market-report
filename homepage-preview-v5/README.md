# معاينة مُسدل — الصفحة الرئيسية، النسخة الخامسة

الرابط العام: https://ahmads-cell.github.io/alboshoot-market-report/homepage-preview-v5/index.html

النسخة الحالية تشمل تعديلات 5 أكتوبر 2026: أرضية بيضاء، الهوية البورغندي، خط Noto Naskh Arabic الأصلي للنصوص والعناوين، مع أحجام أوضح وتباعد سطور مريح، أسهم هيرو أنعم، أسماء فئات بالرمادي المعتمد وأسهم قريبة، مسافات مريحة، وأسعار دون العبارة التوضيحية.

`index.html` و`assets/` هما المعاينة التفاعلية المنشورة. الملفات في `source/` مرجع للواجهة؛ التطوير المحلي الكامل موجود في مشروع `homepage-preview-v5` على جهاز العمل. هذا البناء مهيأ لمسار GitHub Pages المحدد أعلاه.

يمكن تجربة بانرات الهيرو اليدوية والبحث والتنقل بين المنتجات وقائمة الموبايل. روابط المنتجات تفتح صفحات المنتجات التفاعلية الحالية. لا يوجد ربط للشراء أو حساب العميل؛ هذه نسخة لمراجعة الفريق قبل التنفيذ على سلة.

الصورة والشعار والفونت والباترن أصلية من الأصول المعتمدة. التحقق المحلي شمل 1440 و390 بكسل وغياب التجاوز الأفقي. المرحلة التالية: التغليف وملف تسليم المصمم والطباعة بعد تأكيد المقاسات والخامات.

تحديث قسم التفاصيل للموبايل: النص والرابط فوق صورة النسيج مباشرة، دون لوحة سوداء مستقلة أسفلها. الرابط: «شاهد القطعة».

صفحات الكوليكشن — 5 أكتوبر 2026: صفحات مستقلة للبشوت والعبايات والثياب والفروات داخل `collections/`. روابط الفئات في الهيدر والهوم بيج والفوتر تفتح الصفحة المطابقة. كل صفحة تحتوي هيدرًا مصوّرًا مختصرًا، المنتجات، بطاقات كاملة تفتح صفحات القطع، بانرًا أسفلها ووصفًا خاصًا بالفئة. فلتر الموسم متاح لكل الفئات: الكل، شتوي، صيفي، ربيعي؛ التصفّح يظهر عند أكثر من اثنتي عشرة قطعة، مع روابط HTML مستقلة للصفحات التالية.

المحتوى مكتوب مسبقًا داخل HTML: عنوان ووصف وcanonical وOpen Graph وCollectionPage وBreadcrumbList. صور WebP بأحجام 400/800 مع حجز أبعادها وتحميل الصور السفلية عند الحاجة. المعاينة تستخدم `noindex,follow` حتى تأكيد الكتالوج الحقيقي ودومين المتجر؛ لا Product/Offer schema لأسعار التصوّر. الربط بالشراء وتنفيذ سلة خارج نطاق هذه المعاينة.

البناء المحلي: `npm run build`. لبناء GitHub Pages استخدم `node node_modules/vite/bin/vite.js build --base /alboshoot-market-report/homepage-preview-v5/` ثم `node scripts/prepare-sites-build.mjs` و`node scripts/build-collections.mjs`. الصور الإضافية للبشوت والعباية تولّدت عبر Imagegen مع الحفاظ على القطعة الأصلية. سجل البرومبتات: `D:/Musdal/collection-build-2026-10-05/generation-prompts.json`.

تحديث بطاقات الكوليكشن: ستة نماذج بشوت بصور مستقلة، بحدّ 12 منتجًا في الصفحة؛ القطع الست الحالية تظهر معًا. بطاقة واحدة قابلة للنقر بالكامل لصفحة المنتج. لا معاينة سريعة، ولا رابط اكتشف كل القطع، ولا دليل مقاسات داخل الكوليكشن. عداد العرض بالأرقام بين قوسين، وأسماء كاملة تشمل اللون والزري والطابع الخفيف أو السميك في الأمثلة. سجل التسمية محفوظ في AGENTS.md.

البشوت الشتوية: الأسود والبني السميك. المواسم محفوظة كحقول مستقلة، والفلتر يعيد الصفحة إلى الأولى ويحافظ على اختياره خلال التصفح. الموسم غير المتاح يظهر معطلاً. سجل الصور الجديدة والبرومبتات: D:/Musdal/collection-revision-2026-10-05/image-generation.json.

صفحة المنتج — 5 أكتوبر 2026: مبنية من مخطط التقرير في الهوية المعتمدة. معرض صور مرتبط بالقطعة وتكبير، دليل قياس توضيحي بالسنتيمتر فقط، مقاس ولون/نسخة وهدية، تقدير توصيل غير متاح بوضوح، سلة تجريبية تحفظ خياراتها في الجلسة، تفاصيل وعناية وخدمة وأسئلة وحالة مراجعات فارغة وبدائل. خيارات التطريز وتعديل الطول والتغليف مفعّلة للتجربة، وتُحفظ في السلة مع معاينة الاسم وموضعه ومراجعة الاختيارات؛ تكاليفها ومهلها وسياساتها تُعتمد قبل البيع. الشريط السفلي للموبايل يرجع إلى منطقة الاختيار ولا يغطي المحتوى. الصور والمقاسات والأسعار أمثلة معاينة وليست مخزونًا أو وعودًا تشغيلية؛ noindex مستمر. تفاصيل اللون والزري في الكروت كتاج صغير وخفيف؛ عبارة الزري لا تُفصل داخلها.

حجم صفحة الكوليكشن المعتمد: 12 منتجًا لكل صفحة ولكل فلتر موسم. تفاصيل التنقل بين الصفحات ستُراجع لاحقًا عند زيادة الكتالوج.

تحسين المنتج: ثلاث صور مطابقة لكل قطعة مع أسهم السابق/التالي وتكبير، رسم قياس مستقل لكل فئة، مواصفات متقاربة، حفظ وتعديل المقاس والاسم والخيط والطول والتغليف ورسالة الهدية في سلة الجلسة. إجمالي السلة للقطع وحدها، ورسوم الخدمات غير مشمولة بعد. صور الموضع أمثلة من مخطط الفئة؛ المعاينة النصية مستقلة عن صورة المثال. سجل الصور المولّدة بالطريقة المدمجة والبرومبتات ومسارات الحفظ: D:/Musdal/product-refinement-2026-10-05/image-generation.json.

تحديث صور القماش وتجربة الاختيار: لكل قطعة صورة قريبة للنسيج وأخرى للداخل والخياطة؛ للعباية والثوب الأبيض صورة توضيحية لطريقة فحص الضوء، مع توضيح أنها لا تثبت الشفافية الفعلية. تكبير بأصل أكبر، ومصغرات تتمرّر داخل المعرض على الموبايل. التخصيص ظاهر دائمًا، والقياسات بالسنتيمتر فقط. اللون والزري والموسم تاجز ناعمة، والوصف العلوي للمناسبة والهدية مختلف عن وصف التفاصيل السفلي. لا اختيار تلقائي للمقاس، والتنبيه عند عدم اختياره جملة كاملة مستقلة عن الملخّص. سجل توليد الأصول: D:/Musdal/product-closeups-2026-10-05/image-generation.json.

تحديث مواصفات المنتج: «القماش» بدل «التركيب»، مع أيقونات SVG خطية برغندية وفواصل أفقية خفيفة، وأعمدة قريبة وواضحة على الموبايل والديسكتوب. الأيقونات أصلية ومطابقة لأسلوب الموقع؛ لا تُنسب إلى كانفا. أسماء المواصفات محفوظة نصيًا، والأيقونات مخفية عن قارئ الشاشة.

تحسين رسومات دليل القياس: أربعة رسومات تقنية أصلية أوضح للقصّة والياقة والكم والفتحة الأمامية، مع نهايات قياس مستقلة لكل فئة. فتحة كم البشت تُقاس أفقيًا من الحافة إلى الحافة، مع تفصيل مكبّر عند اختيارها؛ طول الكم قياس مختلف. قياس الياقة في الثوب يظهر على شريط مفرود. لا تغيير على قيم المقاسات التوضيحية؛ الوحدات بالسنتيمتر فقط.
